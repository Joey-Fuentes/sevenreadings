# Douay-Rheims Bible, Challoner revision (DRB)

The Douay-Rheims Bible (Rheims New Testament 1582, Douay Old Testament
1609-10) as revised by Bishop Richard Challoner (1749-52); public domain.

Text shipped: the "Bible Text" section of every chapter page of John Paul
Wohlscheid's Haydock transcription (https://gitlab.com/JohnBlood/haydock,
the same pin as the Haydock commentary), 73 books. Cross-reference marks
and bracketed references are removed; the chapter summaries printed above
each chapter are not kept. Numbering is the Vulgate's and is mapped to this
app's canonical ids at ingest (the Douay number is kept as a label), so
Psalm 22 in this text is Psalm 23 in the others.

License of the transcription: none stated; treated as public domain for
the reasons recorded in `sources/haydock/NOTICE.md`. The transcription
omits a few verses (e.g. Genesis 5:32, 25:34, 49:25); the build report lists
them. An explicitly licensed alternative exists should one ever be wanted:
https://github.com/xxruyle/Bible-DouayRheims (MIT, JSON, 73 books).
