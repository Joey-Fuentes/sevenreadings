# byz — Byzantine Majority Text (Robinson-Pierpont 2018)

*The New Testament in the Original Greek: Byzantine Textform*, edited by
Maurice A. Robinson and William G. Pierpont (2018 edition, with the
maintainers' later corrections), as published in the official repository
<https://github.com/byztxt/byzantine-majority-text>.

We ship the accented Unicode text without apparatus
(`csv-unicode/ccat/no-variants/*.csv`), generated by the repository
maintainers from Dr. Robinson's Beta-code source files. Paragraph marks are
dropped; verse numbering is the edition's own (the Received Text numbering).
