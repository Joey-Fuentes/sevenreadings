# Byzantine Majority Text (Robinson-Pierpont 2018)

The New Testament in the Original Greek: Byzantine Textform, edited by
Maurice A. Robinson and William G. Pierpont; 2018 edition with the
repository maintainers' later corrections.

Released to the public domain. The repository
https://github.com/byztxt/byzantine-majority-text (pinned by commit in
`sources.toml`, release v3.3.2) is licensed under The Unlicense, and its
README states: "All the code and text contained in this folder is in the
Public Domain." The editors' own notice adds: "Anyone is permitted to copy
and distribute this text or any portion of this text. It may be
incorporated in a larger work ... without prior notification, permission,
compensation to the holder, or any other restrictions."

Text shipped: the accented Unicode text without apparatus
(`csv-unicode/ccat/no-variants/*.csv`). Changes: paragraph marks are
dropped; verse numbering is the edition's own. Attribution to Dr. Robinson
is requested by the editors, not required.
