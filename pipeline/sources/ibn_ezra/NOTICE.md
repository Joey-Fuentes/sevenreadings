# Ibn Ezra on Tanakh

The commentary of Rabbi Abraham ibn Ezra (1089-1167); the Hebrew is public
domain.

English text shipped: from Sefaria's database export
(huggingface.co/Sefaria/database_export, pinned by commit in
`sources.toml`), chosen per book by the license Sefaria records, exactly as
for Rashi (see `sources/rashi/NOTICE.md`): only Public Domain, CC0, CC BY
and CC BY-SA versions are read. The modern translations Sefaria holds under
restrictive terms (H. Norman Strickman and Arthur M. Silver, Menorah
Publishing, 1988-2004, and any CC-BY-NC version) are never read; M.
Friedlander's Ibn Ezra on Isaiah (1873) is public domain. Coverage in
English is therefore partial, and the build prints which books got a
version and which did not.

Numbering is the Masoretic Text's, mapped as for Rashi.
